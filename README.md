## 🇰🇷 한국어

**안녕하세요! 1인 개발자이자 풀스택 엔지니어입니다.**

응용 프로그램(앱)을 개발하고 배포하는 일을 주 사업으로 하고 있습니다. 기획과 디자인부터 서버 구축, 출시까지 혼자 맡고 있으며, 사용자의 일상을 더 편하게 만드는 편의 기능과 다양한 서비스를 운영하고 있습니다.

### 현재 운영 중인 서비스
- **반려동물 관리 앱** (Android / iOS): 반려동물의 일상 관리와 건강 관리를 돕는 앱
- **부동산 사기 예방**: 계약 전에 전세·부동산 사기를 확인하고 피할 수 있도록 돕는 서비스
- **치매 예방**: 두뇌를 활발하고 건강하게 유지하도록 돕는 인지 훈련 서비스

### 앞으로의 계획
게임 분야로도 영역을 넓혀, **Steam** 플랫폼에서 게임 서비스를 운영할 계획입니다.

외주와 프리랜서 문의는 언제든 환영합니다. 아이디어부터 출시까지 맡길 개발자를 찾으신다면 편하게 연락 주세요!
